# AgentDesk

AgentDesk is a static, single-page workbench for developers and small teams to organize tasks assigned to AI tools or completed with AI assistance. It keeps the brief, tool or owner, priority, and review status visible in one task queue. It does not run prompts or communicate with AI services.

## Features

- Create, edit, and delete tasks with a title, context, tool/owner, status, and priority.
- Move tasks through planned, in progress, in review, and done.
- Search task titles, details, and tool/owner labels; filter by status and priority.
- See live task counts and useful empty states.
- Keep changes in browser `localStorage`, with a confirmation-protected workspace reset.
- Start with a small, clearly marked example queue; examples can be edited or deleted like any other task.
- Responsive layout and accessible form labels, dialog keyboard handling, and visible focus states.

## Run

Open `index.html` directly in a modern browser, or serve the `artifacts/agentdesk` directory with any static file server. No install, backend, account, or configuration is needed.
